## 🚀 How to Host This Website for FREE on GitHub Pages (In Under 2 Minutes)

GitHub Pages provides **100% free hosting forever** with an SSL certificate (`https://`), high-speed global CDN delivery, and zero server maintenance.

### 📋 Prerequisites (Quick 1-time setup)
1. If you don't already have one, create a free account at [github.com](https://github.com/).
2. Copy your assets into the `portfolio\assets\` folder:
   - Copy `AASHNA GUPTA . PIC.jpeg` from your Desktop into `Desktop\Project\portfolio\assets\` and name it `profile.jpg`.

---

### Method A: Browser Upload (Recommended — No Code / No Terminal Needed)

1. **Create a New Repository on GitHub**:
   - Go to [github.com/new](https://github.com/new).
   - Repository name: enter `portfolio` (or `<your-username>.github.io` if you want it as your primary website).
   - Set visibility to **Public** (required for free GitHub Pages).
   - Leave "Add a README file" unchecked (we already have this README).
   - Click **Create repository**.

2. **Upload Your Files**:
   - On the new repository page, click the link that says **"uploading an existing file"** (or click **Add file** -> **Upload files**).
   - Open your folder: `Desktop\Project\portfolio\`.
   - Select and drag all the files (`index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder) into the GitHub upload area in your browser.
   - At the bottom of the page, click the green button **"Commit changes"**.

3. **Turn on GitHub Pages (One-Click Activation)**:
   - In your repository on GitHub, click the **Settings** tab (gear icon at the top right).
   - On the left sidebar menu, click **Pages**.
   - Under **Build and deployment**:
     - **Source**: Select `Deploy from a branch`.
     - **Branch**: Select `main` (or `master`), and folder `/ (root)`.
     - Click **Save**.
   - Wait 30–60 seconds, and refresh the page!
   - GitHub will display your live URL:  
     👉 **`https://<your-username>.github.io/portfolio/`**

Open Command Prompt, PowerShell, or Git Bash in this folder:

```bash
# Link to your new GitHub repository (replace with your username and repo name)
git remote add origin https://github.com/<YOUR-USERNAME>/portfolio.git

# Push to GitHub
git push -u origin main
```
Then go to **Settings** -> **Pages** in your repository and set branch to `main` and save!
